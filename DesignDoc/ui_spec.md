# 画面仕様書 (UI/UX Specification)

## 1. デザインテーマ＆コンセプト
本アプリケーションは「クトゥルフ神話 (CoC Mythos Theme)」をモチーフとした、神秘的で洗練されたダークUIで構築されています。

### 1.1 カラーパレット (CoC Mythos Palette)
- **バックグラウンド**: Eldritch Void (`#040711`, `#0f172a`)
- **プライマリ / アクセント (深海発光グリーン)**: Emerald / Teal (`#2dd4bf`, `#14b8a6`)
- **セカンダリ / アクセント (触手パープル)**: Eldritch Purple (`#a855f7`, `#9333ea`)
- **警告・ファンブル (血色レッド)**: Blood Crimson (`#f43f5e`, `#e11d48`)
- **ハイライト・金飾 (エルドリッチゴールド)**: Eldritch Gold (`#fbbf24`, `#f59e0b`)

### 1.2 視覚効果 (Visual Effects)
- **Glassmorphism**: 透過ガラス風パネル (`backdrop-blur-xl`, `bg-slate-950/70`, 薄いボーダー境界線)
- **フォント**: モダン Sans-serif Typography (Inter / Sans-serif)

## 2. 画面レイアウト・コンポーネント構成

画面は単一ページ (Single Page Application) で構成され、以下の主要エリアで構築されています。

```
+-------------------------------------------------------------------+
|  [Header]  アイコン | ココフォリア Log Analyzer [CoC]   [使い方] [GitHub]  |
+-------------------------------------------------------------------+
|  [Intro Banner]  CoC ダイス出目可視化ツール                          |
|                  タイトル: ココフォリア Log Analyzer [CoC]            |
+-------------------------------------------------------------------+
|  [Input Section]                                                  |
|  - [ファイル指定・アップロード] [サンプルログ] [クリア] ボタン        |
|  - ドラッグ＆ドロップ対応 textarea ログ入力領域                   |
+-------------------------------------------------------------------+
|  [Results Section] (ログ入力時にリアルタイム自動表示)             |
|  - [全体ダイス統計] タブ  |  [探索者別統計 (N名)] タブ             |
|  - 統計カード (総数, クリティカル率, ファンブル率)                 |
|  - 出目分布スペクトル Chart (1D100 10区間バーチャート)            |
+-------------------------------------------------------------------+
|  [Footer]  ココフォリア Log Analyzer [CoC] • Next.js & React 19   |
+-------------------------------------------------------------------+
```

## 3. 各コンポーネント詳細仕様

### 3.1 ヘッダー (Header)
- **タイトル**: `ココフォリア Log Analyzer` + `CoC` バッジ
- **サブタイトル**: `クトゥルフ神話TRPG ダイス出目解析ツール`
- **ナビゲーションリンク**:
  - `使い方`: 公式使い方ページへの外部リンク (新しいタブで開く)
  - `GitHub`: リポジトリへの外部リンク (新しいタブで開く)

### 3.2 インプットセクション (Input Section)
- **アクションボタン群**:
  - `HTMLファイルを指定・アップロード`: ローカルファイルダイアログを開き、指定された `.html` ファイルを即座に読み込んで解析。
  - `サンプルログ`: 「市　太郎」「須磨　ゐる」などの定義済みサンプルHTMLログをセットし即座に解析。
  - `クリア`: 入力テキスト・ファイル名・解析結果をクリア。
- **ドラッグ＆ドロップ / テキストエリア**:
  - ドラッグオーバー時に枠線がエメラルドグリーンに発光する演出。
  - 入力文字の変更 (`onChange`) に伴い、**解析ボタン不要でリアルタイムに解析結果を自動更新**。

### 3.3 結果表示セクション (Results Section)

#### タブ切替 (Tabs)
- **全体ダイス統計**: ログ全体の全プレイヤー合計の統計情報およびヒストグラムを表示。
- **探索者別統計 ({N}名)**: 探索者（キャラクター）ごとの統計カードとヒストグラムを個別にカード化して縦並び表示。

#### 統計カードコンポーネント (StatCard)
- **総判定数**: ダイスコマンド抽出総数
- **決定的成功 (クリティカル)**: 回数および全体に占める割合 (%)
- **致命的失敗 (ファンブル)**: 回数および全体に占める割合 (%)

#### 出目分布ヒストグラムチャート (HistogramChart)
- **ライブラリ**: `Chart.js` (`react-chartjs-2`)
- **X軸**: 1D100の出目 10区間 (`1~10`, `11~20`, ..., `91~100`)
- **Y軸**: 判定回数
- **テーマ配色**:
  - 全体統計: 深海発光グリーン〜グラデーション
  - 探索者別統計: 触手パープル〜グラデーション
