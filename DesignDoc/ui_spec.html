画面仕様書 (UI/UX Specification)

ココフォリア Log Analyzer [CoC] • クトゥルフ神話 TRPG ダイス出目解析ツール

1. デザインテーマ＆コンセプト

本アプリケーションは「クトゥルフ神話 (CoC Mythos Theme)」をモチーフとした、深海エルドリッチの神秘的かつ洗練されたダークUIで構築されています。

1.2 視覚効果 (Visual Effects)

  • Glassmorphism: 透過ガラス風パネル (Backdrop blur, 1px 境界線発光)
  • Dynamic Micro-animations: ドラッグ＆ドロップ領域の発光アニメーション、パルサーランプ、タブ切替時のフェードイン効果

2. 画面レイアウト構成

画面は単一ページ (Single Page Application) で構成され、上部から順に以下の要素がレイアウトされています。

セクション 構成要素 主な役割・表示内容
ヘッダー
(Header)		 • ブランドアイコン
• アプリタイトル (`ココフォリア Log Analyzer [CoC]`)
• ナビゲーションリンク (`使い方`, `GitHub`) 		画面上部に固定配置。ブランド表示および使い方ガイド／GitHubリポジトリへの外部リンクを提供します。
イントロバナー
(Intro Banner)		 • カテゴリバッジ (`CoC ダイス出目可視化ツール`)
• メインキャッチコピー
• 機能概要説明文 		画面上部の案内エリア。アプリケーションの目的（CCB/CCの1D100出目可視化）を簡潔に明示します。
インプットセクション
(Input Section)		 • `HTMLファイルを指定・アップロード` ボタン
• `サンプルログ` ボタン
• `クリア` ボタン
• ドラッグ＆ドロップ対応テキストエリア 		ログデータの読み込みエリア。ファイルの参照・ドロップ・貼り付けを行うと同時に**リアルタイム自動解析**が実行されます。
結果表示セクション
(Results Section)		 • タブ切替 (`全体ダイス統計` / `探索者別統計`)
• 抽出判定件数バッジ
• 統計カード (`StatCard`)
• 1D100 出目分布チャート (`HistogramChart`) 		解析結果をグラフィカルに可視化。全体および探索者ごとの判定数、クリティカル率・ファンブル率、ヒストグラムを描画します。
フッター
(Footer)		 • コピーライト表記
• 使用技術スタック名 (`Next.js & React 19`) 		画面最下部に配置されるシンプルなフッター領域。

3. 各コンポーネント詳細仕様

コンポーネント名 役割・機能仕様 動作・インタラクション
Header ブランド表示および関連リンクの提供 「使い方」「GitHub」への外部リンク（別タブでオープン）
Upload Button ローカルHTMLファイルの指定読み込み クリックでファイルダイアログ表示。指定された `.html` を即座に読み込んで自動解析。
Sample Log Button 動作確認用のデモログ読み込み 「市　太郎」「須磨　ゐる」等を含むサンプルHTMLログをセットし即座に解析。
Textarea & Dropzone ログHTMLの貼り付け・ドロップ領域 ドラッグ時に枠線がエメラルド発光。テキスト入力・ペーストと同時にリアルタイム自動解析。
Tabs (Overall/Users) 全体統計と探索者別統計の表示切り替え 全体統計タブと探索者（ユーザー）別統計タブをスムーズに切り替え。
StatCard 総判定数、クリティカル・ファンブル率表示 判定総数、決定的成功（％）、致命的失敗（％）をハイコントラストカードで表示。
HistogramChart 1D100出目分布スペクトルの描画 Chart.js による 10区間 (`1~10`〜`91~100`) のバーチャート可視化。
