Python 3.14 バージョンアップに伴う修正計画

Python 3.8 / 3.9系から3.14へのバージョンアップに伴い、現状のコードや依存ライブラリにおいて以下の修正が必要となります。

1. 依存ライブラリ (requirements.txt / Pipfile) の更新

対象パッケージ 修正内容 原因・理由
不要なパッケージの削除 未使用のパッケージや推移的依存関係を削除し、メインの依存ライブラリのみを記載しました。また、パッケージ管理ツールを pipenv から uv に移行するため、Pipfile を廃止し、標準的な pyproject.toml を作成しました。（なお、App Engine へのデプロイ用に requirements.txt は残しております。） 不要なパッケージや間接的な依存関係をリストから除外することで、Python 3.14環境構築時に最新版が自動解決されやすくなり、依存関係の競合や不要なエラーを防ぐためです。
Flask, pandas, matplotlib, numpy 等のメインパッケージ Python 3.14 をサポートする最新バージョンがインストールされるようにバージョン指定を解除 古いバージョンのままでは Python 3.14 で削除されたモジュールや変更された内部APIにより動作しない、またはビルドに失敗するためです。

2. CI/CD および設定ファイルの修正

対象ファイル 修正内容 原因・理由
.github/workflows/main.yml actions/checkout@v4 および actions/setup-python@v5 等、最新のGitHub Actionsへのアップデート 現在指定されている v2 アクションは古く、Node.js 12の非推奨警告が出ます。また、最新バージョンのPython (3.14) を正常にセットアップするためには、アクション自体のアップデートも不可欠です。
パッケージ管理 (Pipfile等) Pipfile と Pipfile.lock を削除し、pyproject.toml へ移行 高速で最新のパッケージ管理ツールである uv を用いることで、Python環境のセットアップや依存関係の解決をより速く、安全に行うためです。
