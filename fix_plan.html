Python 3.14 バージョンアップに伴う修正計画

Python 3.8 / 3.9系から3.14へのバージョンアップに伴い、現状のコードや依存ライブラリにおいて以下の修正が必要となります。

1. 依存ライブラリ (requirements.txt / Pipfile) の更新

対象パッケージ 修正内容 原因・理由
Flask, Werkzeug, Jinja2 最新のメジャーバージョン（Flask 3.x系, Werkzeug 3.x系など）へのアップデート Werkzeug 2.0.1 等の古いバージョンは、Python 3.10で削除された collections.Mapping などを参照しているため、Python 3.14環境ではインポートエラーとなり動作しません。
numpy, pandas, matplotlib Python 3.14 をサポートする最新バージョンへのアップデート C言語などのネイティブ拡張を含むライブラリであるため、Python 3.14用の最新のビルド（Wheel）パッケージを利用しないとインストールが失敗する可能性が高いです。
その他 (mkdocs 等) 必要に応じた最新版へのアップデート Python 3.13 / 3.14で完全に削除された標準ライブラリ（cgi, distutils, imp等）に依存している古いパッケージは動作しなくなるためです。

2. CI/CD および設定ファイルの修正

対象ファイル 修正内容 原因・理由
.github/workflows/main.yml actions/checkout@v4 および actions/setup-python@v5 等、最新のGitHub Actionsへのアップデート 現在指定されている v2 アクションは古く、Node.js 12の非推奨警告が出ます。また、最新バージョンのPython (3.14) を正常にセットアップするためには、アクション自体のアップデートも不可欠です。
Pipfile.lock pipenv lock による再生成 Python 3.14で利用可能な依存関係ツリーに更新し、新しいハッシュ値とバージョンを記録するためです。
